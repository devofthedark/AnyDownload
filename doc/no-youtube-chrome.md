# Why can't I download from YouTube on Chrome?

**Short Answer:** Because it's the only way Google will let us put AnyDownload on the 
Chrome Web Store.

**Long Answer:** Google has consistently fought against people downloading videos from
YouTube. In fact, a large portion of code within AnyDownload is solely dedicated to
being able to download from YouTube simply because Google has made it so difficult. 
Since Google runs the Chrome Web Store, they will naturally not allow any extension that
can download from YouTube on their platform. This means that the version of AnyDownload
hosted on the Chrome Web Store has downloading from YouTube disabled. You can still download
from any other website normally, just not from YouTube.

## I want to download from YouTube. What can I do?

Good news! You are not out of options here. You can still download from Youtube by following
the instructions below.

### If you are on the Microsoft Edge browser:

Download AnyDownload from [Edge Add-ons](https://microsoftedge.microsoft.com/addons/detail/anydownload/icpkdhomdhnooolmlgipoiaejfoadcfb) 
instead of the Chrome Web Store. The version of AnyDownload on Edge Add-ons is able to download
from YouTube.

### If you are on another Chromium-based browser (Chrome, Brave, etc.):

Download and install AnyDownload directly from GitHub using the [instructions](/README.md#chromium-install)
found in the README. You are not missing future updates this way, as AnyDownload includes a built-in
auto-updater when installed from outside extension stores.
